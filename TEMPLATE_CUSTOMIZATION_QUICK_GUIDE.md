# 🎨 Guide Rapide - Customisation des Templates

## 🚀 Démarrage Rapide

### Comment Accéder
1. Aller sur la page **Templates** (`/templates`)
2. Choisir un template
3. Cliquer sur **"Customize"**

## 🎯 Navigation Principale

### Barre Supérieure (Top Bar)
```
[← Retour] | Customize Modern Boutique | [Desktop] [Tablet] [Mobile] | [Reset] [Draft] [Apply ✓]
```

## 💡 Astuces d'Utilisation

### Workflow Rapide

1. **Choisir un style général**
   - Cliquer sur une palette de base
   - Ou cliquer sur "Sharp" / "Soft" preset

2. **Affiner les couleurs**
   - Cliquer sur les grands carrés colorés
   - Ajuster avec le color picker
   - Cliquer "Apply"

3. **Personnaliser le look**
   - Ajuster Border Radius avec slider
   - Toggle Shadows et Hover Effects
   - Choisir une animation

4. **Activer les fonctionnalités**
   - Cliquer sur les cartes de features désirées
   - Vérifier le compteur "Active Features"

5. **Prévisualiser**
   - Utiliser Device Selector (Desktop/Tablet/Mobile)
   - Voir les changements en temps réel

6. **Sauvegarder**
   - "Draft" pour tester plus tard
   - "Apply" pour publier sur la boutique

## 🔄 Réinitialisation

### Options de Reset

1. **Reset All Colors** (dans Custom Colors section)
   - Supprime toutes les couleurs custom
   - Retour à la palette de base

2. **Reset Button** (dans color picker)
   - Supprime la couleur custom de cette couleur uniquement

3. **Reset Global** (Top Bar)
   - Réinitialise TOUTES les customizations
   - Demande confirmation
