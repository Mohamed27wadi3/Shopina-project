## Animation Indicators

### Button Hover States
```
Normal:      [Button Text]
Hover:       [Button Text] ↑ (scale-105)
             Glow effect intensifies
Active:      [Button Text] ↓ (scale-95)
```

### Tab Transition
```
Click         Smooth Gradient      Active State
[Normal] ──→  Gradient Transition ──→ [Active]
              (300ms duration)
```

### Card Elevation
```
Normal:      Card with subtle shadow
Hover:       Card lifts up (shadow-lg)
             Smooth transition (300ms)
```
