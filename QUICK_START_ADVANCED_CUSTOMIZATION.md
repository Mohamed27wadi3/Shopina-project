# 🚀 Guide Rapide - Page Personnalisation Avancée

## 📍 Accès rapide

### URL directe
```
http://localhost:3000/templates/1/customize-advanced
```

### Via le flux normal
1. **Allez sur**: http://localhost:3000/templates
2. **Cliquez**: "Voir les variantes" sur un template
3. **Cliquez**: "Continuer la personnalisation"
4. **Cliquez**: "⚙️ Personnalisation avancée" (nouveau bouton)

## 🎮 Navigation dans la page

### Barre d'outils
```
[← Back]          | Retour à la page de base
[Desktop/Tablet/  | Changez de dispositif d'aperçu
 Mobile]          |
[Reset]           | Réinitialise tous les changements
[Draft]           | Sauvegarde un brouillon
[Apply]           | Applique à votre boutique
```

### Onglets latéraux
```
🌟 Branding       | Nom, tagline, logo
🎨 Colors         | Couleurs primaire et accent
📐 Layout         | Header, grille produits, footer
⚙️ Advanced       | Styles, animations, espacement
```

## 💡 Exemples d'utilisation

### Exemple 1: Boutique de luxe
```
Onglet "Layout":
  • Header: Sticky
  • Colonnes produits: 3
  • Image ratio: 1:1 (carré)
  • Afficher évaluations: ON

Onglet "Advanced":
  • Rayon angles: 16px
  • Espacement: 32px (grand)
  • Ombres: ON
  • Animations: fade
```

### Exemple 2: Startup technologique
```
Onglet "Branding":
  • Nom: "TechHub"
  • Tagline: "Innovation at your fingertips"
  • Logo: [Upload tech logo]

Onglet "Colors":
  • Primary: #0077FF
  • Accent: #5AC8FA

Onglet "Layout":
  • Header: Standard
  • Colonnes: 4
  • Quick Add: ON

Onglet "Advanced":
  • Rayon: 8px
  • Espacement: 24px
  • Animations: slide
```

### Exemple 3: Boutique minimale
```
Onglet "Advanced":
  • Rayon: 0px (aucun arrondi)
  • Espacement: 16px (compact)
  • Ombres: OFF
  • Animations: none (rapide)
```

## ✨ Conseils & astuces

### 💾 Sauvegarder votre travail
```
1. Personnalisez votre boutique
2. Cliquez sur [Draft]
3. Ses modifications sont sauvegardées
```

### 🔄 Réinitialiser les changements
```
1. Cliquez sur [Reset]
2. Confirmez la réinitialisation
3. La page recharge avec les paramètres par défaut
```

### 📱 Prévisualisation responsive
```
• [Desktop] - Vue complète (1440px+)
• [Tablet]  - Vue tablette (768px)
• [Mobile]  - Vue mobile (375px)
```

### 🎨 Changements de couleur
```
1. Cliquez sur le carré de couleur
2. Sélectionnez une couleur
3. Ou tapez un code hex
4. L'aperçu se met à jour en temps réel
```

## 🎯 Cas d'usage courants

| Cas | Solution |
|-----|----------|
| Je veux plus d'espacement | Augmentez "Espacement" à 32px |
| Je veux des coins arrondis | Augmentez "Rayon" à 16px |
| Je veux plus de produits visibles | Réduisez les colonnes à 2 |
| Je veux un effet plus moderne | Activez les ombres et animations |
| Je veux un design épuré | Réduisez l'espacement à 16px, rayon à 0px |

## 🐛 Dépannage

### Q: Les changements n'apparaissent pas
**R**: Attendez 1-2 secondes pour que le HMR se mette à jour

### Q: La couleur n'est pas bonne
**R**: Assurez-vous du format hex (ex: #FF0000)

### Q: La prévisualisation est floue
**R**: Sélectionnez "Desktop" pour une meilleure vue

### Q: Je veux annuler
**R**: Cliquez sur [Reset] ou rechargez la page

## ⌨️ Raccourcis clavier
