## 🎨 Color Palette in Action

### Primary Color (#0077FF) Usage
```
BUTTONS:           [ASSOCIATE TO MY STORE] - Gradient Blue→Cyan
LINKS:             ← Back navigation in blue
HIGHLIGHTS:        Selection borders, active states
BADGES:            Step indicator badge
ICONS:             Info icons, checkmarks
HOVER EFFECTS:     Scale 1.05 with blue shadow
FOCUS STATES:      Blue ring with offset
```

### Secondary Color (#5AC8FA) Usage
```
GRADIENTS:         Blue→Cyan accent (buttons, tabs)
SHADOWS:           Glow effect on hover (shadow-[#0077FF]/30)
ACCENTS:           Card corners, badge backgrounds
TEXT COLORS:       Secondary information (prices, dates)
LINKS:             Secondary navigation
HOVER STATES:      Fade from blue to cyan
```

### Dark Mode Colors
```
BACKGROUNDS:       Gray-900 (darker backgrounds)
CARDS:             Gray-800 (slightly lighter)
TEXT:              White / Gray-300 (readable)
BORDERS:           Gray-700 (subtle dividers)
SHADOWS:           Gray-900/50 (darker shadows)
```

## ✨ Animation Examples

### Button Hover
```
Before: [Button] - Static, flat
Hover:  [Button] ↗ - Scale 1.05
        Blue glow effect appears
        Shadow expands (shadow-lg)
After:  Smooth 300ms transition
```

### Tab Activation
```
Before: [Tab] - Gray background
Click:  Gradient transition starts
During: Blue→Cyan gradient fills
After:  White text appears
        Colored shadow glows
```

### Card Hover
```
Before: shadow-sm (subtle)
Hover:  shadow-md → shadow-lg (elevated)
        Smooth elevation effect
        Border brightens slightly
```

## 🎬 User Journey

### Step 1: Browse Templates
```
User navigates to /templates
Sees grid of template cards
Each shows preview image
```

### Step 2: View Variants
```
User clicks "Voir les variantes"
Navigates to /templates/:id/variants
Sees variant cards
Can select each variant
Sees customization options
```

### Step 3: Customize
```
User clicks "Continuer la personnalisation"
Navigates to /templates/:id/customize
Fills in shop details
Selects colors and styles
Previews live
```

### Step 4: Publish
```
User clicks "Associer à ma boutique"
System saves configuration
User sees success message
Navigates to /my-shop
```
